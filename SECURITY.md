# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue.** Instead, email security concerns to the project maintainers.

## Scope

This is a reference project for demonstrating testing patterns. It is not intended for production deployment. However, we take security seriously in the patterns we demonstrate — insecure patterns in a reference project can propagate to real applications.

## What to report

- Insecure coding patterns in the reference implementations
- Dependency vulnerabilities
- Secrets or credentials accidentally committed
- SQL injection, XSS, or other OWASP Top 10 issues in example code

## Response

We aim to acknowledge reports within 48 hours and resolve confirmed issues within 7 days.
